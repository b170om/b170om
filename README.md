## Featured project

**[football-xg-analysis](https://github.com/b170om/football-xg-analysis)**
Predicting football match outcomes (home win / draw / away win) from expected goals (xG)
and Elo ratings, using 10,330 matches from six European leagues, 2014/15-2018/19 (Understat data via Kaggle).

- Leakage-safe features: rolling xG built only from earlier matches, pre-match Elo and league position
- Chronological split by season (train 2014/15-2016/17, validate 2017/18, test 2018/19); the test season was used once
- Final model: 52.1% test accuracy vs. 44.7% for an "always predict home win" baseline
